# 科学模型、24 矿物双晶全量核查与教学边界说明 · Crystal Optics Science Notes (V2.1)

《像素晶体（PixelCrystal V2.1）》脱胎于 SUVA 晶体光学互动科普体系，将严谨的几何结晶学（点群对称、倒易点阵晶面法线、真实单形与双晶律）及线性晶体光学数值模型与 **16-bit Risograph 孔版像素视觉（PRISMA PIXEL OPTICS）** 相结合。为确保趣味游戏化不混淆严谨科学边界，特此公开全套物理模型、24 种矿物全量核查表及文献依据。

## 1. 核心数学与物理模型 vs. 教学边界

| 模块 | 严谨物理与几何结晶学依据 | 教学简化与边界说明 |
| :--- | :--- | :--- |
| **布拉维格子与倒易法线 (`buildLatticeBasis`, `millerNormal`)** | 按真实晶胞参数 $(a, b, c, \alpha, \beta, \gamma)$ 建立笛卡尔基矢 $M$，由倒易张量 $M^{-T}(h, k, l)^T$ 严格求解任意晶系 $(hkl)$ 晶面单位外法线 $\hat{n}_{hkl}$，经半空间交集 $n_i \cdot x \le d_i$ 精确切割凸多面体（全部单晶/双晶个体满足欧拉示性数 $V - E + F = 2$）。 | 聚形工坊生长距离滑块 $d_{hkl}$ 代表理想几何截角比例（Wulff 几何形态），不代表热液/岩浆动力学实时生长速率；像素配色采用“一色一单形”教学编码，不等同矿物真实体色。 |
| **双晶律与三维凹角投影 (`buildInclinedContactTwin`)** | 接触双晶沿精确倒易晶面法线 $\hat{n}_{hkl}$ 对半空间集合施以镜面反射 $H = I - 2\hat{n}\hat{n}^T$ 或二次双晶轴 $180^\circ$ 旋转，并在双晶结合面处精确裁剪主副单体，由晶体三维坐标实时投影结合面迹线与凹入角锚点。 | 自然界双晶极罕见的宝石（如电气石、绿柱石、磷灰石、锆石、托帕石、坦桑石、石榴石）在图鉴中明确标注为 **`RARE TWIN LAW`（罕见文献双晶律对照）**；达碧兹祖母绿明确标注为 **`GROWTH SECTOR`（六扇区连生生长构造，非严格晶格双晶）**，绝不用随机晶簇冒充双晶。 |
| **赫尔曼-莫甘点群对称 (`symmetrySpecForPointGroup`)** | 严格区分 32 点群对称要素：如电气石 `3m` 具极性单向异极 `+c/-c`（仅 `L3 + 3P`，无对称中心 `C`、无水平 `L2`）；黄铁矿 `2/m3̄` 仅 `3L2 + 4L3i + 3P + C`（无 `L4`）；磷灰石 `6/m` 无水平 `L2`；石英 `32` 手性对映无 `P/C`。 | 三维舞台以像素轴线标示主要结晶轴与旋转对称轴方向，帮助初学者建立三维方位感。 |
| **光率体、菲涅耳 $2V$ 与金属光学 (`optics-core.js`)** | 将逆介电张量 $B = \operatorname{diag}(n_X^{-2}, n_Y^{-2}, n_Z^{-2})$ 投影至波法线横平面 $D \cdot s = 0$ 精确对角化；双轴晶光轴角由精确菲涅耳正切公式 $\tan V_z = \sqrt{\frac{n_\alpha^{-2} - n_\beta^{-2}}{n_\beta^{-2} - n_\gamma^{-2}}}$ 反算；不透明金属矿物（黄铁矿 `FeS₂`）采用反射矿相学复折射率反射率 $R \approx 54.5\%$，不伪造透射折射率。 | 透射偏光模型假设理想均匀、无内应力单晶平行平板；天然钻石/尖晶石常见的异常应变双折射不在理想均质张量中伪造。 |
| **锥光干涉图与石英旋光牛眼 (`renderConoscopeBuffer`)** | 采用琼斯微层矩阵传递同时耦合线双折射与圆双折射（石英旋光率 $\rho = 21.7^\circ/\text{mm} @ 589.3\text{ nm}$），支持 `+530 nm` 一级红石膏试板加减色判定光性正负。 | 锥光图是后焦面晶内波法线角度分布图而非放大晶体像；像素版光栅化为 `56×56` 视场以匹配复古街机显像框。 |
| **冰洲石走离、色散靶与比重台** | 冰洲石由坡印廷矢量 $S \parallel E \times H$ 计算寻常光 `o` 与非常光 `e` 走离角（菱面体解理面正入射实算约 $6.2^\circ$）；石英/方解石采用 Ghosh (1999) 色散方程，刚玉采用 Malitson & Dodge (1972) Sellmeier 方程；折光仪接触液上限设为 `1.790`（`OTL` 超限保护）；静水比重基于阿基米德定律。 | 游戏内四站取证仅供科普娱乐教学，不能替代具备 CMA/CNAS/GIA 资质实验室的实测鉴定证书。 |
