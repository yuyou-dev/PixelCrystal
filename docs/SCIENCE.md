# 科学模型与教学边界说明 · Crystal Optics Science Notes

《像素晶体（PixelCrystal）》脱胎于 SUVA 晶体光学互动科普体系，将严谨的线性晶体光学数值模型与 **16-bit Risograph 孔版像素视觉（PRISMA PIXEL OPTICS）** 相结合。为确保趣味游戏化不混淆严谨科学边界，特此说明各模块物理依据与教学近似：

---

## 1. 实测文献常数 vs. 教学游戏模型

| 模块 | 数值物理依据 | 教学简化与边界说明 |
| :--- | :--- | :--- |
| **晶体多面体与聚形锻造 (`crystal-meshes.js`)** | 半空间交集 $n_i \cdot x \le d_i$ 精确求解凸多面体；尖晶石律沿 `(111)` 面旋转 `180°` 生成真实 `141°04'` 双晶凹角；面角由外法线点积精确反算。 | 生长距离滑块代表理想几何形态截角比例，不代表真实热液动力学晶体生长速率；像素配色采用“一色一单形”教学编码，不等同矿物真实体色。 |
| **光率体与双折射本征模 (`optics-core.js`)** | 将逆介电张量 $B = \operatorname{diag}(n_X^{-2}, n_Y^{-2}, n_Z^{-2})$ 投影至波法线横平面 $D \cdot s = 0$，精确对角化求解 $n_{\text{fast}}, n_{\text{slow}}$ 及双轴晶光轴角 $2V$。 | 假设理想均匀、无内应力单晶平行平板；天然钻石/尖晶石常见的异常应变消光不在理想均质张量中伪造。 |
| **锥光干涉图与石英牛眼 (`renderConoscopeBuffer`)** | 采用矩阵指数 $U = \exp(iH)$ 同时求解线双折射与圆双折射（石英旋光张量取自 Arteaga 2009 实测拟合），支持 `530 nm` 一级红石膏试板加减色判定光性正负。 | 锥光图是晶内波法线角度分布图而非放大晶体像；光栅化为 `56×56` 像素视场，服务于像素街机直观辨识。 |
| **冰洲石双折射走离 (`calciteDoubleRay`)** | 由电位移 $D$ 反推电场 $E_i = D_i / n_i^2$ 与坡印廷能流向量 $S \parallel E \times H$，按真实板厚计算寻常光 `o-ray` 与非寻常光 `e-ray` 出射分离距离。 | 平行平板正入射模型，忽略表面菲涅耳多次反射损耗。 |
| **棱镜色散激光靶场 (`prismDispersionFan`)** | 石英、方解石采用 Ghosh (1999) 色散式，刚玉采用 Malitson & Dodge (1972) Sellmeier 方程；其余棱镜演示介质采用标注的柯西教学色散系数计算斯涅尔折射与全内反射临界角 $\theta_c = \arcsin(1/n)$。 | 激光靶场将色散扇面角度作可视化展示，不等同宝石鉴定室分光镜实测吸收谱证。 |
| **宝石折射仪与静水比重 (`refractometerShadow` / `hydrostaticSG`)** | 接触液上限设为 `1.79`（钻石 `2.418`、锆石 `>1.92` 真实呈现“超量程 OTL”）；静水称重采用 Tanaka (2001) 水密度公式与阿基米德浮力定律。 | 游戏内鉴定结果仅供科普娱乐教学，不能替代具备 CMA/CNAS/GIA 资质实验室的实测鉴定证书。 |
